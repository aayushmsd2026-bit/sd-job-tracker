# Sustainability & Green Finance Job Tracker

A small static site listing sustainability, climate and green finance roles in Nepal, plus remote roles open to Nepali applicants.

- `index.html`: the page. It reads `jobs.json` and needs no build step.
- `jobs.json`: the job list. It is refreshed every week.
- `UPDATE_GUIDE.md`: the rules for the weekly refresh (sources, status rules, fit score).

Hosted on GitHub Pages from the `main` branch.
